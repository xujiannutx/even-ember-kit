# even-ember-kit



拿来练手的小仓库

## 用法

```bash
cat data.txt | python main.py
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/even-ember-kit.git
cd even-ember-kit
pip install -r requirements.txt
```
